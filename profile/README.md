# CMSHands

CMSHands is a WordPress plugin plus a hosted service. The plugin adds a chat screen to wp-admin and three small rescue files. The service runs the assistant, reads the site through the plugin, proposes a change as a card, and applies it only after an administrator presses OK. Each applied change is reversible from the same card. A daily health check runs on the free plan and crash reports are immediate.

Requirements: an administrator login, WordPress 6.3 or newer with PHP 8.0 or newer for the full feature set, reduced features back to WordPress 4.0 and PHP 5.6, one site per install. Page builders such as Elementor, Divi and Beaver Builder are not supported yet.

Plugin download and setup: https://cmshands.com/get
Free checklists and sample files: https://cmshands.com/guides
